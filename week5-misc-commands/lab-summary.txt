1. What does `uname -a` display?
   Displays kernel name, hostname, kernel version, and system architecture.

2. How do you make an alias permanent?
   Add it to ~/.bashrc file.

3. What's the difference between `>` and `>>` with echo?
   > overwrites the file, >> appends to the file.

4. What does `wc` output without any flags?
   Lines, words, bytes (characters), and filename - in that order.

5. How is `shred` different from `rm`?
   rm just removes the file while shred securely deletes it by overwriting it 3 times before removal.

6. What's the purpose of `traceroute`?
   Shows the network path packets take from your system to a destination, displaying each router (hop) along the way.
